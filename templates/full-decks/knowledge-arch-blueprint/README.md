# knowledge-arch-blueprint

크림 종이(`#F0EAE0`) 바닥 + 러스트 레드 (`#B5392A`) 단일 액센트 + 단단한 검정색 스트로크 카드 + 점선 피드백 루프 화살표. 에서 영감을 받은 `20260405 아키텍처빌드이미지v2.html`  - 그것은 건축 청사진과 같은 실제 "기술 백서 아키텍처 다이어그램"입니다.

**시각적 특성:** 따뜻한 베이지색 종이 베이스, 청사진 느낌을 위한 약한 48px 그리드, 견고한 2px 검은색 테두리 카드, 영웅 상자가 늘어선 파이프라인 단계 상자, 오른쪽 상단 통찰력 빨간색 설명선, 대문자 및 소문자 키커 2.5-4px 커닝, SVG 피드백 루프 점선 + 화살표, Playfair 큰 글꼴 크기 세리프 데이터, 그라데이션 없음 및 그림자 없음, 극도로 절제됨.

**사용할 경우:** 시스템 아키텍처, 데이터 흐름 및 프로세스 분해에 대해 이야기합니다. 콘텐츠가 마케팅 게시물이 아닌 진지한 기술 백서처럼 보이길 원합니다. 진지함과 인쇄가 필요하며 README에 스크린샷을 직접 삽입할 수 있습니다.
