# 발표자 모드 공개 · 발표자 모드 템플릿

축어적 초안과의 기술 공유를 위해 특별히 설계된 전체 데크 템플릿입니다. 핵심 판매 포인트는 실제로 사용할 수 있는 **자기 카드 스피커 보기**입니다. 현재 페이지 iframe 미리보기 + 다음 페이지 iframe 미리보기 + 큰 글꼴 축어 초안 + 타이머, 카드 4개를 마음대로 드래그/확대할 수 있으며 모두 통합되어 있습니다. `runtime.js` 여기서는 종속성이 없습니다.

## 사용 시나리오

- 기술공유/테크톡(30~60분)
- 제품 출시 컨퍼런스 기조 연설자
- 강좌 전달
- 대본을 읽지 않고 단어를 따라야 하는 공식적인 연설**

## 빠른 시작

```bash
cp -r templates/full-decks/presenter-mode-reveal examples/my-talk
open examples/my-talk/index.html
```

## 키보드 조작

| 열쇠 | 액션 |
|---|---|
| `S` | 스피커 창 열기(새 창이 팝업되고 원본 페이지는 변경되지 않음) |
| `T` | 테마 전환(5개 사전 설정) |
| `←` `→` | 페이지 넘기기 |
| `Space` / `PgDn` | 다음 페이지 |
| `F` | 전체 화면 |
| `O` | 개요 썸네일 |
| `R` | 타이머 재설정(발표자 보기에서만) |
| `Esc` | 모든 오버레이 닫기 |

## 주제 전환

템플릿은 연설 시나리오에 적합한 5가지 테마로 사전 설정되어 있습니다. `<html data-themes="...">` 속성에서:

```html
<html lang="zh-CN" data-themes="tokyo-night,dracula,catppuccin-mocha,nord,corporate-clean">
```

언론 `T` 사이클 전환. 무엇이든 변경할 수 있습니다 `assets/themes/*.css` 내부 테마입니다.

## 축어 원고 작성 기준

**모든 페이지 `<aside class="notes">` 150~300단어**를 작성하세요. 세 가지 철칙:

1. **강의노트가 아닌 알림** — 핵심 내용은 굵은 글씨로 표시하고, 전환 문장은 단락별로 구분하고, 데이터는 명확하게 나열합니다.
2. **페이지당 150~300단어** — 페이지당 2~3분 속도
3. **말로 쓰기** — "그러므로" → "그래서"; "이 계획" → "이 계획"; 한 번 읽어보고 주저하지 말고 이야기해 보세요.

예:
```html
<aside class="notes">
  <p>큰한글한글,한글한글한글큰한글한글한개 <strong>한글더한글한글한글의한글테마</strong> - ...</p>
  <p>한글한글한글한개청중한글:<em>만들기 PPT 한글발표 PPT 는한글파일일</em>.</p>
  <p>직접다음한글한글보임사용 3 개예시한글한글한글이개청중한글...</p>
</aside>
```

지원되는 인라인 태그:
- `<strong>` — 하이라이트(주황색)
- `<em>` — 이탤릭체 강조(파란색)
- `<code>` — 고정 폭 글꼴
- `<p>` — 세분화(세그먼트당 30~60초의 콘텐츠 권장)

##수정/확장

- **페이지 추가**: 원하는 항목을 복사하세요. `<section class="slide">` 차단하고 내용을 변경하고 `<aside class="notes">`
- **테마 변경**: 변경 `data-themes` 목록을 작성하거나 직접 변경 `<link id="theme-link" href="...">`
- **스타일 변경**: 이동만 가능 `style.css`, 루트 디렉터리를 건드리지 마세요 `assets/base.css`
- **애니메이션 추가**: 요소에 애니메이션을 추가합니다. `data-anim="fade-up"` 등 (참고 `references/animations.md`)

## 스피커 창용 카드 4개

언론 `S` 팝업 창에는 다음이 포함됩니다.

- 🔵 **CURRENT** — 현재 페이지 iframe 미리보기(로드 중 `?preview=N` 모드, 픽셀 완벽, 뷰어와 동일한 CSS/테마/글꼴)
- 🟣 **NEXT** — 전환 준비에 도움이 되는 다음 페이지 미리보기
- 🟠 **발표자 스크립트** — 큰 글꼴로 된 축어적 스크립트, 스크롤 가능
- 🟢 **타이머** — 경과 시간 + 페이지 번호 + 이전/다음/재설정 버튼

카드 작업:
- **카드 헤더 드래그** (컬러 점 + 헤더 상단 바) → 카드 이동
- **카드 오른쪽 하단 드래그** → 크기 조정
- 위치 + 크기는 localStorage에 자동으로 저장되며 다음에 열 때 복원됩니다.
- 하단의 "레이아웃 재설정" 버튼을 누르면 기본 카드 배열을 복원할 수 있습니다.

부드러운 페이지 넘기기: iframe은 한 번만 로드되고 후속 페이지 넘기기는 통과됩니다. `postMessage` 내부 슬라이드를 전환합니다. **다시 로드하지 않고 깜박임이 없습니다**. 두 개의 창문이 지나간다 `BroadcastChannel` 양방향 동기화.

## 메모

- **시청자는 절대 볼 수 없습니다. `.notes` 콘텐츠** — CSS 기본값 `display:none`, 발표자 보기에만 표시됩니다.
- **슬라이드 본문에 자신만을 위한 단어를 쓰지 마세요** — 모든 프롬프트가 켜져 있어야 합니다. `<aside class="notes">` 내부
- **듀얼 스크린 음성**: 켜기 `index.html` S를 눌러 스피커 창을 띄우고, 청중 창을 프로젝션/외부 화면으로 드래그합니다. F를 전체 화면으로 드래그하면 스피커 창은 자신의 화면에 그대로 유지됩니다.
