3가지 위험 수준, 3가지 치료법

L1 · Green

취소 가능

초안 작성, 사진 생성 및 초안 문서.
Ctrl+Z가 잘못되었습니다. 비용이 0입니다.
전략: 놓아두기

L2 · Amber

반 취소 가능

초안 이메일을 보내고, PR을 제출하고, 스테이징 데이터를 변경하세요.
틀린 경우 사과/롤백하세요.
전략: 직접 검토

L3 · Red

취소 불가

실제 이메일을 보내고, 결제하고, 데이터베이스를 삭제하고, 제품 데이터를 삭제하세요.
당신이 틀렸다면, 당신은 정말 틀린 것입니다.
전략: 하드 카드 + 이중 검토

에이전트가 자동으로 업그레이드되지 않도록 하세요

L1 작업 자체는 L2 작업이 될 수 없습니다. 승인은 명시적이고 취소 가능해야 하며 만료 날짜가 있어야 합니다.

  - tools: [write_draft, generate_image, read_docs]

  - tools: [send_email_draft, open_pr, write_staging_db]
    reviewer: human

level_3_hard_block:
  - tools: [send_real_email, transfer_money, delete_prod]
    unless: two_human_sign_off AND within_24h

forbidden_always:
  - "rm -rf /"
  - "drop table"
  - "force push origin main"
