● 비교

Notion 대 흑요석 · AI 친화성

참고

데이터베이스 네이티브

구조화된 작업 및 팀 협업에 적합하지만 -
• AI는 API를 사용해야 하며 실시간 전체 텍스트를 얻을 수 없습니다
• 중첩 블록 구조가 복잡하고 토큰 비용이 높음
• 잘못된 현지화는 장기 기억으로 사용할 수 없음

흑요석

순수 마크다운 + 이중 체인

본질적으로 AI에 친숙함 -
• 모든 것이 파일이므로 Claude가 직접 읽습니다.
• 이중 체인 = 자연 그래프, 거의 무료로 항목 추출
• 오프라인, git, diff 및 롤백

💡 핵심 통찰:AI에는 "더 똑똑한 데이터베이스"가 필요하지 않고 "스스로 읽을 수 있는 파일 시스템"이 필요합니다.

● SETUP · 4 STEPS

0부터 처음으로 "AI가 메모를 쓴다"

1

Obsidian 설치 + 로컬 REST API 플러그인 열기

단 한 번의 클릭으로 커뮤니티 플러그인을 열 수 있습니다. 이를 통해 외부 프로세스에서 Vault를 읽고 쓸 수 있습니다.

2

Claude Desktop + obsidian-mcp 서버에 연결

MCP는 구성 파일과 연결될 수 있으며 토큰은 볼트의 API 키로 채워집니다.

3

흑요석 스킬 5개 설치

05/08
● MCP 구성

claude_desktop_config.json

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "흑요석": {
      "명령": "npx",
      "args": ["-y", "@modelcontextprotocol/server-obsidian"],
      "env": {
        "OBSIDIAN_API_KEY": "xxxxxxxxxxxxxxxx",
        "OBSIDIAN_HOST": "http://127.0.0.1:27123"
      }
    }
  }
}

Claude Desktop을 다시 시작하고 /mcp를 입력하면 흑요석이 연결된 것을 볼 수 있습니다.
