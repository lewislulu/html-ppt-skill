# obsidian-claude-gradient

GitHub-dark (`#0d1117`) + 보라색 주변 방사형 + 60px 마스크 그리드 + 보라색 → 파란색 → 녹색 그라데이션 텍스트. 에서 영감을 받은 `20260406-obsidian-claude/slides.html` 의 `--accent #7c3aed`,`.cbg` 이중 방사형 커버,`.cgrid` 60px 마스크 그리드 및 `.g` 3스톱 그라데이션.

**시각적 특성:** 어두운 회색 및 파란색 배경 + 보라색 및 파란색 방사형 블룸 + 어두운 격자 마스크, 중앙 제목/텍스트, 둥근 보라색 알약 태그, 선형 `#a855f7→#60a5fa→#34d399` 그라데이션 글꼴, GitHub 같은 코드 색상(`#010409` 배경 + 보라색/파란색/주황색/녹색 토큰), 보라색 왼쪽 테두리 강조 표시 블록, 간결한 단계 목록.

**사용할 경우:** 개발자 친화적인 워크플로, MCP/에이전트/개발 도구 튜토리얼에 대해 이야기합니다. 기질이 GitHub 블로그/선형 변경 로그에 가까워지기를 원합니다. 내용은 주로 구성 파일 + 단계입니다.
