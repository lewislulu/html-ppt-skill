# hermes-cyber-terminal

검정색 바닥(`#0a0c10`) + 터미널 크롬 + 스캔 라인 + 민트 그린 빛의 큰 문자 + JetBrains Mono 전체 텍스트 타자기 느낌. 에서 영감을 받은 `20260414-hermes-agent/ppt/hermes-record.html` 의 `codebox #15151b` 어두운 코드 상자 및 `hermes-vs-openclaw.html` 실제 측정된 비교 기질 - 두 가지를 결합하여 "정직한 사이버 리뷰"로 만듭니다.

**시각적 특성:** 56px 사이버 그리드 + CRT 비네팅 + 반투명 스캔라인 오버레이, 창 신호등 크롬,`$ prompt` 시작 부분의 명령줄 제목, 민트 녹색 텍스트 그림자 광선 `#7ed3a4`, 고정 폭 전역, 스트로크 전용 렌더링이 포함된 가상 막대 차트, 깜박이는 커서, 황색/녹색/빨간색 등급 레이블.

**사용 시기:** 개발자 도구/CLI/에이전트를 평가하고 실행 점수 데이터, 추적 및 차이점을 표시합니다. 즉시 "기술적으로 정직한 리뷰"라는 시각적인 느낌을 주고 싶습니다. 긴 추적/긴 코드 시나리오에 적합합니다.

**Source inspiration:** `20260414-hermes-agent/ppt/hermes-record.html` + `hermes-vs-openclaw.html`.
