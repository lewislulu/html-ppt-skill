증상

잊을 만큼
느껴졌습니다.

  • 어제 얘기했던 프로젝트를 오늘 다시 설명할게요
  • 컨텍스트 창이 도착하자마자 '추억 만들기'가 시작됩니다.
  • 처음 만나는 것처럼 서로 다른 세션 사이에 연결이 없습니다
  • 귀하의 실제 선호사항은 기억되지 않으며 매번 다시 묻는 메시지가 표시됩니다.

The Fix

대답은 '아니요'입니다
더 큰 창.

오히려, 귀하의 지식, 선호도 및 역사를 가져오십시오.파일 시스템에 쓰기.
모든 대화 전에 LLM이 해당 시스템을 읽도록 하세요.

× 창 채우기

모든 것을 신속하고, 비싸고, 느리고, 결국에는 넘치도록 채워 넣으세요.

✓ 파일 + 검색
