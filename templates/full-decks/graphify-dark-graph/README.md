# graphify-dark-graph

깊은 밤의 어두운 바닥 + 강제 지향 지식 그래프 오버레이 + 따뜻한 유리 흉내 카드. 에서 영감을 받은 `20260413-graphify/ppt/graphify.html` 의 `#06060c` 그라데이션 베이스, 떠다니는 구체 빛, 유리 카드(따뜻함/파란색/녹색/보라색 5가지 변형) 및 무지개 텍스트 제목.

**Visual traits:** `#06060c → #0e1020` 경사 그라데이션, 400~520px 흐림 구 느린 부동 3개, 배경으로 SVG 강제 방향 지도 포함, 무지개 이동 그라데이션 제목, JetBrains Mono `.cmd-glow` 명령줄, 상단 하이라이트와 미묘한 내부 그림자가 있는 유리 모방 카드, 따뜻한 색상 액센트(#e8a87c 호박색 / #7ed3a4 민트 / #7eb8da 미스트 블루 / #b8a4d6 라일락).

**사용 시기:** 개발자 도구, 명령줄 제품, 지식 그래프/데이터 시각화 관련 프로젝트를 소개합니다. 라이브 시연 중에 시각적으로 "AI 네이티브 + 기술적 감각 + 따뜻함"을 원합니다.

**Source inspiration:** `20260413-graphify/ppt/graphify.html`.
