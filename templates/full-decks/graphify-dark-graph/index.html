04 / 08

One command

0부터 그래프까지,약 90초

$ graphify ~/notes --out ./graph

# graphify.config.yaml
ingest:
  paths: [~/notes, ~/code/docs]
  include: ["*.md", "*.pdf", "*.py"]

extract:
  model: claude-opus-4-6
  schema: [concept, person, event, relation]

render:
  engine: d3-force
  audit: true     # 각 측파대 소스 범위

Pipeline

Scan

→
🔬
Extract

🕸️

구성 + 중복 제거

🎨
