# xhs-white-editorial

흰색 배경 잡지 스타일, 강조 블록, 마카롱 소프트 카드 그룹화. 에서 영감을 받은 `20260409 업그레이드업그레이드버전지식한글저장소/샤오홍슈이미지한국어/v2-흰하단버전/slide_01_cover.html` 상단 레인보우 바 + 큰 텍스트 제목 `20260412-AI테스트테스트한글안전안전/xhs-ai-testing-safety-v2.html` 의 `.focus` 강한 강조를 위한 검정색 바탕에 흰색 텍스트와 마카롱 소프트 컬러 카드 시스템.

**시각적 특성:** 순백색 배경, 상단의 10색 무지개 막대, 약간의 여백이 있는 거대한 80-110px 제목, 그라데이션 브랜드 텍스트(보라색 → 파란색 → 녹색 → 주황색 → 분홍색), 마카롱 부드러운 색상 카드(소프트 보라색/분홍색/파란색/녹색/주황색), 캡슐 태그 + 점, 검정색 배경 `.focus` 액센트 상자, 밝은 그림자가 있는 영웅 인용 상자.

**사용할 경우:** Little Red Book의 사진과 텍스트 또는 가로 스크린 데크로 사용할 수 있는 흰색 배경 콘텐츠 게시물이 필요합니다. 텍스트가 많고 초점이 촘촘하며 키워드를 한눈에 파악해야 합니다. 주로 중국 독자들을 위한 것입니다.
