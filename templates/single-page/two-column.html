왼쪽 열 · 개념

테마 = CSS 변수 세트. 모든 색상, 글꼴, 둥근 모서리 및 그림자를 수신합니다. :root 내부.

  • — 토큰은 의미를 정의하며 특정 색상 값을 쓰지 않습니다.
  • — 토큰으로 형식화된 base.css
  • — 테마별로 금액만 변경됩니다.

오른쪽 열 · 예

:root {
  --bg: #fff;
  --text-1: #0c0d10;
  --accent: #3b6cff;
  --radius: 18px;
}
.card {
  background: var(--bg);
  color: var(--text-1);
  border-radius: var(--radius);
}
