어떻게 · 핵심 아이디어

:root에 "어떻게 생겼나요"를 포함하세요

개념

색상, 글꼴, 둥근 모서리, 그림자 등 모든 시각적 속성은 의미 변수가 됩니다.

  • --text-1 / --text-2 / --text-3
  • --surface / --surface-2
  • --accent / --accent-2 / --accent-3
  • --반경 / --shadow / --grad

예

/* 자산/테마/aurora.css */
:루트 {
  --bg: #06091c;
  --text-1: #e8f0ff;
  --악센트: #5ef2c6;
  --악센트-2: #7aa2ff;
  --악센트-3: #c984ff;
  --반지름: 20px;
}

- 오로라 테마 전체가 너무 큽니다.

방법
핵심은: base.css는 특정 색상 값이 아닌 변수 이름만 인식한다는 것입니다. 주제를 바꾸다 = 변수를 바꾸다

숫자 · 실제 효과

데크 제작 시간 분포, 사용 전/사용 후

data
사용한 후에는 "콘텐츠 작성"에 소요되는 시간의 비율이 크게 증가하고 다른 모든 항목은 감소했습니다. 이것이 바로 우리가 원했던 것입니다.
