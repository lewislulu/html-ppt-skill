# 프레젠터 모드 가이드 · 스피커 모드 가이드

이 문서에서는 html-ppt 스킬에서 **스피커 모드 PPT를 그대로** 만드는 방법을 설명합니다.

## 스피커 모드를 사용하는 경우

사용자의 요구 사항이 다음 중 하나와 관련된 경우 **스피커 모드가 선호됩니다**:

- "**연설**", "**공유**", "**연설**", "**말 그대로**", "**발표자 노트**" 언급
- "**발표자 보기**", "**발표자 보기**", "**발표자 모드**"에 대한 언급
- "공유하는 데 **30분 / 45분 / 1시간** 필요"
- "팀에게 xxx에 대해 알릴 거예요", "기술 공유를 할 거예요", "로드쇼를 할 거예요"라고 말하세요
- "**말을 잊고 싶지 않다**", "**유창하게 말하지 못할까 봐**", "**텔레프롬프터가 필요하다**" 강조

사용자가 말하지 않고 "정적이고 아름다운 PPT"(샤오홍슈 사진과 텍스트, 제품 앨범, 보고서 슬라이드 등)만 만들고 싶다면 스피커 모드가 필요하지 않습니다.

## 두 가지 접근 방식

### ✅ 권장 사례: 직접 사용 `presenter-mode-reveal` 템플릿

```bash
cp -r templates/full-decks/presenter-mode-reveal examples/my-talk
```

이 템플릿에는 모든 필수 요소가 사전 설정되어 있습니다.
- 발표자 보기를 전환하는 S 키 지원
- T키 사이클로 이용 가능한 5가지 테마(도쿄나이트/드라큘라/캣푸친모카/노르드/기업클린)
- 왼쪽 및 오른쪽 키를 사용하여 페이지를 넘깁니다.
- 각 페이지에는 150~300단어의 샘플 축어 초안이 있습니다.
- 하단에 핵심 힌트가 있습니다.

내용을 직접 변경하면 됩니다.

### 🔧 고급 접근 방식: 기존 템플릿에 스피커 모드 추가

html-ppt의 **S 주요 발표자 보기는 다음과 같습니다. `runtime.js` 내장된 모든 풀 데크 템플릿은 자동으로 지원됩니다**. 다음 두 가지만 수행하면 됩니다.

1. **각 슬라이드 끝에 추가하세요. `<aside class="notes">`**(또는 `<div class="notes">`), 안에 텍스트를 그대로 적습니다.
2. **HTML이 도입되었는지 확인하세요. `assets/runtime.js`**

```html
<section class="slide">
  <h2>당신의제목테마</h2>
  <p>안내용...</p>
  <aside class="notes">
    <p>이여기는발표발표시간한글한글의한글,150-300 원고...</p>
  </aside>
</section>
```

## 축어 쓰기의 세 가지 규칙

이것이 전체 방법론의 핵심입니다. AI는 사용자가 축어 원고 작성을 도울 때 다음을 준수해야 합니다.

### 철칙 1: 연설이 아니라 '큐 신호'입니다

❌ **잘못된 글쓰기 방식** (원고를 읽는 것과 같은):
```
큰한글한글,한글한글한글로한글한글의공유공유.한글한글한글한글한글한글큰한글한글한글한다음한글한글한글팀에서전환한글세개한글만들기의한글한글.
한글한글,한글한글한글보기한다음한글상황한글한글.에서전환한글의세개한글중,한글한글한글로한글한글다음한글개한글테마……
```

✅ **올바른 쓰기**(프롬프트 신호 + 굵은 핵심):
```
<p>한글한글!한글한글공유공유한글한글한글팀<strong>전환한글 3 개한글</strong>의한글한글.</p>
<p>한글한글<em>한글상황</em> - 세개한글현재한글한글한글로한글<strong>세개한글한글한글테마</strong>:
한글한글한글,됨본한글,한글한글한글한글.</p>
<p>직접다음한글발표개발표한글한글한글한글의.</p>
```

**차이점**: 올바른 버전은 핵심 단어를 굵게 표시하고, 전환 문장을 단락으로 분리하여 한눈에 연결할 수 있도록 했습니다.

### 규칙 2: 페이지당 150~300단어

- **150단어 미만**: 프롬프트가 충분하지 않아 문장 중간에 막히게 됩니다.
- **300단어 이상**: 다 훑어볼 시간이 없습니다.
- **2~3분/페이지**가 가장 편안한 속도입니다.

### 규칙 3: 서면 언어가 아닌 음성 언어를 사용하세요.

| ❌작성 | ✅ 음성 |
|---|---|
| 그러므로 | 그러므로 |
| 계획 | 계획 |
| 그러나 | 그러나/아직 |
| 최적화 | 최적화 |
| 우리는 | 우리는 할 것이다 / 다음 |
| 요약하자면 | 간단히 말해서 |

**확인 방법**: 작성한 후 읽어서 말하는 것처럼 들리는지 확인하세요.

## 발표자 보기에 표시되는 콘텐츠

언론 `S` 키를 누르면 **독립적인 발표자 창이 나타납니다**(원본 페이지는 청중 보기에 남아 있습니다). 스피커 창은 **4개의 독립적인 자기 카드**입니다.

```
 청중청중창창(원본페이지한글)           발표발표자창창(자석스냅카드카드)
┌─────────────────┐   ┌─────────────────────┬──────────────────┐
│                 │   │ 🔵 CURRENT         │ 🟣 NEXT            │
│  정상정상 slide     │   │ ━━━━━━━━━━━━━━━━ │ ━━━━━━━━━━━━━ │
│  안전화면한글프롬프트       │◄►│                   │  iframe preview   │
│                 │   │  iframe preview   │  (다음한페이지)         │
│                 │   │  (현재현재페이지)        ├──────────────────┤
│                 │   │                   │ 🟠 SPEAKER SCRIPT  │
│                 │   │                   │ ━━━━━━━━━━━━━ │
│                 │   ├─────────────────────┤  [큰원고글자발표원고원고]   │
│                 │   │ 🟢 TIMER           │  [가능롤백애니]         │
│                 │   │ ⏱ 12:34   3 / 8 │                   │
│                 │   │ [← Prev][Next →]  │                   │
└─────────────────┘   └─────────────────────┴──────────────────┘
       ↑ BroadcastChannel 양방향양방향동기단계넘김페이지 ↑
```

카드 상호 작용 규칙:
- **카드 헤더 드래그**(색상 점과 제목이 있는 상단 표시줄) → 카드 위치 이동
- **카드 오른쪽 하단의 삼각형 핸들을 드래그** → 카드 크기 조정
- **위치/크기는 자동으로 localStorage에 저장되며 다음에 열 때 복원됩니다.
- 하단의 "레이아웃 재설정" 버튼을 누르면 기본 배열이 복원됩니다.

카드 내용:
- 🔵 **현재** — 현재 페이지의 **완벽한 픽셀 미리보기**(iframe은 원본 HTML 파일을 로드함) `?preview=N` 패턴, 잘못된 색상은 불가능합니다)
- 🟣 **NEXT** — 다음 페이지 미리보기, 픽셀 완벽함
- 🟠 **발표자 스크립트** — 축어적 스크립트, 글꼴 크기 18px, 지원 `<strong>` (주황색 굵은 글씨),`<em>` (파란색 강조),`<code>` 등 인라인 스타일
- 🟢 **타이머** — 타이머는 페이지 자르기 버튼으로 초점을 잃지 않습니다.

두 창 동기화: 아무 창에서나 ← →를 눌러 페이지를 넘기면 다른 창은 자동으로 동기화됩니다(BroadcastChannel).

부드럽고 매끄러운 페이지 넘기기: iframe은 한 번만 로드되고 후속 페이지 넘기기에 사용됩니다. `postMessage` 다시 로드하거나 깜박이지 않고 표시되는 슬라이드를 전환합니다.

## 키보드 단축키(스피커 모드)

| 열쇠 | 액션 |
|---|---|
| `S` | 발표자 창 열기(새 창이 팝업되고 원본 페이지는 청중 보기에 남아 있음) |
| `←` `→` / 공간 / PgDn | 페이지 넘기기(발표자 보기에서도) |
| `T` | 테마 전환 |
| `R` | 타이머 재설정(발표자 보기에서만) |
| `F` | 전체 화면 |
| `O` | 개요 |
| `Esc` | 모든 오버레이 닫기 |

## 듀얼 스크린 스피치의 표준 프로세스

1. 오픈 `index.html`, 누르다 `S` → 스피커 창 팝업
2. **관청자 창**(원본 페이지)을 투사/외부 화면으로 드래그한 후 `F` 전체 화면
3. 눈앞의 화면에 있는 **스피커 창**(팝업 창)을 그대로 둡니다.
4. 아무 창에서나 ← →를 눌러 페이지를 넘기면 양쪽이 자동으로 동기화됩니다.
5. 스피커 창에서 텍스트 보기 + 다음 페이지 + 타이머 보기

> 💡 **미리보기가 픽셀 단위로 완벽한 이유**: 모든 미리보기는 `<iframe>`, 동일한 데크 HTML 파일을 로드하지만 URL이 더 많습니다. `?preview=N` 매개변수.`runtime.js` 이 매개변수가 감지되면 페이지 N만 렌더링되고 모든 크롬이 숨겨집니다. **iframe은 뷰어 보기와 정확히 동일한 CSS, 테마, 글꼴 및 뷰포트를 사용합니다** - 색상과 타이포그래피의 일관성이 보장됩니다. 외부 레이어에 CSS 사용 `transform: scale()` 1920×1080을 카드의 너비와 높이로 축소하면 비례적으로 크기를 조정해도 이미지가 변형되지 않습니다.

> 💡 **깜박이지 않는 이유**: iframe은 초기 로딩 후 상주하며 페이지를 넘길 때 발표자 창이 전달됩니다. `postMessage({type:'preview-goto', idx:N})` iframe에 페이지 N으로 전환하도록 지시합니다. iframe 전용 스위치 내부의 Runtime.js `.is-active` 클래스, **다시 로드 없음, 흰색 화면 렌더링 없음**.

## 일반적인 실수

### ❌ 슬라이드의 보이는 위치에 원고를 그대로 작성합니다.

```html
<!-- 오류오류:이단락한국어원고청중청중보임보기로 -->
<p style="font-size:12px;color:gray">
  이여기발표 xxx,자연후발표 yyy...
</p>
```

✅ 정답:
```html
<aside class="notes">
  <p>이여기발표 xxx,자연후발표 yyy...</p>
</aside>
```

`.notes` 클래스 기본값 `display:none`, 발표자 보기에만 표시됩니다.

### ❌ Runtime.js 소개를 잊어버렸습니다.

아니요 `<script src="../../../assets/runtime.js"></script>` = S 키 없음, 발표자 보기 없음, 페이지 넘김 없음.

### ❌ 축어적 초안에는 서면 언어를 사용하세요.

AI 로봇처럼 발음됩니다. **꼭 작성 후 다시 읽어보세요**.

### ❌ 페이지당 50단어

프롬프트가 충분하지 않으면 단어는 여전히 잊혀질 것입니다.

### ❌ 페이지당 500단어

내 눈은 그것을 전혀 스캔할 수 없습니다. 즉, 아무것도 쓰지 않았다는 의미입니다.

## AI를 사용하여 축어 원고에 대한 표준 프롬프트 생성

> "각 슬라이드마다 **150~300자**의 초안을 축어적으로 작성하여 넣어주세요. `<aside class="notes">` 내부.
> 요구사항:
> 1. 서면 언어가 아닌 **음성 언어**를 사용합니다(그래서/그러나/다음, 그러므로/그러나/위의 모든 것은 아님)
> 2. **핵심 키워드**를 사용하세요 `<strong>` 굵게
> 3. 전환 문장은 독립된 단락을 형성합니다(문단당 1-3 문장).
> 4. 읽는 소리는 읽는 소리가 아니라 말하는 소리와 비슷합니다.
> 5. 마지막에는 다음 페이지로 이어지는 자연스러운 전환이 있어야 합니다."

## 추천 조합

- **테마**:`tokyo-night`(어둡게, 기술 공유에 선호),`corporate-clean`(밝은색상, 사업보고서),`dracula`(어두운 색상 옵션)
- **글꼴**: 기본 Noto Sans SC + JetBrains Mono, 변경할 필요 없음
- **애니메이션**: 제한적으로 사용,`fade-up` / `rise-in` 가장 자연스러운 것, 사용하지 마세요 `glitch-in` / `confetti-burst` 뭔가 그럴싸한데
- **페이지 수**: 공유하는 데 30분 = 8~12페이지; 45분 = 12~16페이지; 1시간 = 16~22페이지
